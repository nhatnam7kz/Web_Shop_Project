# Web Shop – Website bán đồ lưu niệm và thời trang

Website bán hàng trực tuyến quy mô nhỏ, chuyên bán đồ lưu niệm và thời trang phong cách gaming: áo phông, áo nỉ, cốc bình, mô hình lego, giày dép, combo quà tặng...

## Thành viên nhóm

| STT | Họ và tên |
|---|---|
| 1 | Hoàng Nhất Nam |
| 2 | Đinh Đức Vương |
| 3 | Phạm Tuấn Kiệt |
| 4 | Nguyễn Đức Nguyên |

## Công nghệ sử dụng

- **HTML5, CSS3** (Flexbox, Grid, giao diện responsive)
- **JavaScript** thuần (không dùng framework)
- **JSON** để lưu dữ liệu sản phẩm
- **localStorage** để lưu giỏ hàng, yêu thích, tài khoản
- **Git / GitHub** để làm việc nhóm

## Chức năng chính

- Trang chủ: banner, danh mục, sản phẩm nổi bật, đồng hồ đếm ngược khuyến mãi
- Xem danh sách sản phẩm, tìm kiếm, lọc (giá, size, màu) và sắp xếp
- Xem chi tiết sản phẩm: nhiều ảnh, chọn size, số lượng
- Giỏ hàng: thêm, sửa số lượng, xóa, tính tổng tiền
- Đặt hàng và thanh toán (mô phỏng), có mã đơn hàng
- Đăng ký, đăng nhập, xem lại đơn hàng đã đặt
- Danh sách yêu thích
- Trang liên hệ, giới thiệu và các trang chính sách

## Cách chạy

1. Tải dự án về máy:
   ```
   git clone git@github.com:nhatnam7kz/Web_Shop_Project.git
   ```
2. Mở file `index.html` bằng trình duyệt (Chrome, Edge hoặc Firefox).

Nếu ảnh hoặc sản phẩm không hiện, hãy mở dự án bằng VS Code với tiện ích **Live Server**.

## Lưu ý

Website chỉ có phần giao diện, không có máy chủ hay cơ sở dữ liệu thật. Tài khoản và đơn hàng chỉ được lưu trong trình duyệt của máy đang dùng; việc thanh toán chỉ là mô phỏng.
